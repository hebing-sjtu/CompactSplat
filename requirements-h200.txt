# Dependency set for H200 (sm_90) nodes whose image ships torch 2.12.0+cu126.
#
# Install with the companion constraints file so pip can never move torch:
#   pip install -r requirements-h200.txt -c constraints-image.txt
#
# Differences from requirements.txt, which is pinned to torch 2.4.0 / cu124:
#   - xformers dropped. Its only use site (encoder/unimatch/ldm_unet/cross_attention.py)
#     is guarded by try/except and honours XFORMERS_DISABLED, so attention falls back
#     to the plain PyTorch path. A torch-2.4 xformers wheel cannot load under 2.12.
#   - numpy moved off 1.24.4: torch 2.12 wheels are built against the numpy 2 ABI,
#     and 1.24.4 has no cp312 wheels.
#   - pytorch_lightning bumped to 2.5.x for torch 2.12 compatibility.
#   - moviepy stays below 2.0 because model_wrapper.py imports moviepy.editor,
#     which 2.x removed.
